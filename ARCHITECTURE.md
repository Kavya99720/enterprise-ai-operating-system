# System Architecture

## Frontend
The frontend provides the user interface where users can chat with the AI, upload files, and manage their account.

## Backend
The FastAPI backend handles requests, authentication, and communication with the AI services.

## AI Engine
The AI engine processes user queries and coordinates LLMs, RAG, and AI agents.

## Database
Stores users, chat history, and application data.

## Vector Database
Stores embeddings for semantic search and RAG.

## File Storage
Stores uploaded PDFs, DOCX, CSV, and other documents.
